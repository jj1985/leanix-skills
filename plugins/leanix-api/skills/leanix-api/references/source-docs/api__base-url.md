# Base URL

Find your base URL to use in API requests or configurations.

The SAP LeanIX base URL
varies among customers. In our documentation, the base URL appears as follows:

```text
https://{SUBDOMAIN}.leanix.net
```

**Tip**

Copy the subdomain value from your workspace URL. If you need help accessing the
workspace, contact your workspace administrator.
