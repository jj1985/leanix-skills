# Custom Reports

Learn how to build custom reports tailored to your organization's needs.

## Overview

SAP LeanIX offers a wide
range of standard, ready-to-use reports for visualizing and analyzing your workspace data.
When the standard reports don't meet your needs, you can build custom reports instead.

Custom reports in LeanIX are
applications built using the [Reporting Library and Custom Report Tools](https://help.sap.com/docs/leanix/ea/reporting-framework-and-cli?locale=en-US&state=PRODUCTION&version=CLOUD "Build custom reports using the SAP LeanIX Reporting Library and Custom Report Tools."), which
provide the necessary APIs, components, and project structure. They allow you to retrieve,
transform, and visualize data from your workspace.

## Ways to Build Custom Reports

There are two ways to build custom reports. Both approaches
use the same underlying tools and project structure, and you can also combine them. For
example, use AI to define the basic structure of your report and refine the code manually to
add detail.

| Method | How it Works | Best if You |
| --- | --- | --- |
| [Standard Custom<br>Reports](https://help.sap.com/docs/leanix/ea/building-your-first-custom-report?locale=en-US&state=PRODUCTION&version=CLOUD "Learn how to create custom reports that visualize applications by business criticality.") | Write React and TypeScript code<br>directly. | Prefer to write the code yourself. |
| [Custom Reports with<br>AI](https://help.sap.com/docs/leanix/ea/custom-reports-with-ai?locale=en-US&state=PRODUCTION&version=CLOUD "Build custom reports in SAP LeanIX by describing what you want in natural language without manual coding.") | Describe what you want in plain<br>language. | Want to generate a report without writing<br>code. |
